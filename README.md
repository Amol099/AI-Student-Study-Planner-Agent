# 🎓 AI Student Study Planner Agent

An AI-powered study planning assistant built using **n8n** and **Google Gemini** to help students prepare effectively for exams. The agent generates personalized study schedules, practice quiz questions, revision checklists, and useful study tips based on the user's input.

---

## 📌 Project Overview

Preparing for exams can be stressful, especially when students are unsure how to organize their study time. This project automates the planning process using an AI agent built with n8n and Google Gemini.

The user enters the subject and available study days, and the AI generates a customized study plan in seconds.

```text

      │
      ▼

      ▼

      │
      ▼
Google Gemini
      │
      ▼
Study Plan
```

---

 How to Run

1. Install n8n Community Edition.
2. Get a Google Gemini API key from Google AI Studio.
3. Import the `workflow.json` file into n8n.
4. Configure your Gemini API credentials.
5. Activate the workflow.
6. Open the chat interface and start using the Study Planner Agent.
